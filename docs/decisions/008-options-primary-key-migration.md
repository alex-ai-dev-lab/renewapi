# ADR-008：补齐旧 Options 表的实际主键

状态：已接受。日期：2026-09-23。

当前 Option 模型已有 `primaryKey`，但实际复现表明，只有 key 唯一索引的旧表不会被 GORM AutoMigrate 自动升级为主键。已满足主键要求的数据库保持 NOOP。

新增独立迁移 `options-primary-key:v1`，不修改已执行迁移的版本标识。MySQL/PostgreSQL 原位添加主键；SQLite 在同一连接和事务中重建两列表，保留配置值、索引、触发器及外键引用，并恢复原外键检查开关。存在 NULL key、重复 key 或不兼容的自定义结构时返回错误，不能自行删除配置或选择覆盖值。

配置写入仍使用现有事务和运行时回滚机制。保留原定价选项，仅修正 key 条件的跨数据库引用方式；不引入批量价格重置。迁移及价格写入/回滚验证同时进入开发分支数据库工作流。
