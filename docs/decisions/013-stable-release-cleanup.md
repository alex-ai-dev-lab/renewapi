# ADR-013：首次正式版与授权历史清理

状态：已接受。日期：2026-10-02。

## 决策

- 本轮 Obsidian 界面、任务式菜单和混合模型映射组成首个正式版 `v1.0.0`。
- 按用户要求直接在 `main` 提交，不创建新工作分支。产品标签为 `renewapi-v1.0.0`，Release 名称为 `RenewAPI v1.0.0`，镜像为 `renewapi:1.0.0`。
- 沿用统一 GitHub Actions 门禁和 Releases 离线分发：后端、双前端、四版本数据库及真实浏览器验证全部通过，两个架构构建、迁移和下载校验完成后公开。
- 已公开附件与标签指向不覆盖、不移动。失败的产品标签构建通过重跑验证；需要改变源码时先保持产品标签未创建，避免重指向。

## 此次清理授权

用户明确要求删除以前版本镜像及标签，并在 2026-10-02 确认“全部历史发布与标签”：清点时有 5 个旧 Release、65 个附件、79 个标签，包括 74 个无 Release 的标签，以及本轮生成的临时构建版；最终只保留新正式版。

仅在替代正式版发布成功且下载校验通过后，按保存清单删除旧 Release、其附件及旧标签。执行前重新比对清单与标签 SHA，避免误删并发新增资源。该授权不包括删除源码提交、分支、生产数据或 Actions 运行记录。

本决策为本次明确授权的例外，补充 ADR-010 的历史清理条款；后续清理仍须获得对应范围的明确授权。
