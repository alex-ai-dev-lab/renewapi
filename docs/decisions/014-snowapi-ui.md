# ADR-014：SnowAPI 界面层与 RenewAPI 业务边界

状态：已接受。日期：2026-10-02。

用户要求推翻旧界面，整体采用 SnowAPI 的 UI、配色和模块布局，并明确选择保留现有业务规则。

以 `Ooxygen7/SnowAPI@fe0afe6c9d388b2fcf0659ffc05c07925477c470` 的 AGPL 前端作为界面来源，保留来源和版权说明。默认首页以演示站的 Snowflake 设计为准，控制台复用 Astryx 外壳及其表格、导航和页面语言。

API 鉴权、账务、渠道保存、模型映射和后台配置以 RenewAPI 实现为准。迁移时用明确的接口适配接回现有能力；不启用 demo 数据适配器，不把上游固定订阅档位或独有风控规则变成本站业务规则。不存在的业务能力不得显示为可执行功能。

保留已有深链接和兼容入口，视觉过时的代码在引用清理后退出。最终以真实后端、各角色浏览器流程及业务契约回归验证，不以页面成功编译作为迁移完成标准。

首次载入新版时，将旧主题的配色、字体、圆角、缩放和布局偏好切到 SnowAPI 默认值，防止旧绿色主题继续生效；明暗和文字方向偏好独立保留，新浏览器默认明亮。以后保留用户的新选择。

新界面需要的日志多类型筛选、流向图和 Token 汇总仅查询现有消耗记录，不新增账务或转发规则。流向图依照管理员/本人权限裁剪维度，Token 汇总仅返回当前账户数据，页面明确使用账户口径；没有历史节点数据时不虚构节点维度。
