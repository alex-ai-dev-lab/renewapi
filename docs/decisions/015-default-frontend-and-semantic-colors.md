# ADR-015：默认前端唯一构建与语义色边界

状态：本地实现，尚未发布。2026-10-05。

用户明确要求修复当前 UI 审计发现，并允许删除旧前端、旧资源和无用依赖。

- `web/default` 是唯一构建和嵌入的前端。删除 classic 的源码、依赖、构建阶段和切换入口；最后一个包含 classic 的已发布镜像是 v1.1.3。
- 保留 `theme.frontend` 的历史配置键，`classic` 值在运行时归一化为 `default`，不修改历史数据库。已知旧控制台地址保留查询参数并跳转到当前路由。回退依赖旧镜像，不再依赖已移除的 UI 切换。
- 默认布局保持中性；用户选择的预设可改变主色和表面。成功/警告/信息/危险色相独立于图表和品牌预设，文字使用专用墨色。不得用全局原生色板子串选择器压成灰阶。
- 新用户使用统一的正常密度默认值。已有 cookie、旧偏好和用户选择不得因默认版本变化而无条件重置。
- 输入边界、强制颜色焦点、最小触控目标、语言标记和主内容/Portal 一致性是共享组件的职责。图表用文字、线型和符号补充颜色，不宣称颜色本身可覆盖所有色觉差异。
- 维护对比度、语义色稳定性、预设实际生效和 forced-colors 检查；历史 Aurora 验收结果仅作历史证据。

本决策补充 ADR-014 并替代 classic 退役文档中的“继续双构建”阶段。保留 Git 历史、署名、真实业务数据以及生产仍使用的旧分块缓存。
