# ADR-021：请求复制、限流存储与长流生命周期

状态：Accepted。日期：2026-10-17。尚未发布。

## 决策

- RawMessage 深拷贝使用独立字节存储；不共享可变正文，不用 unsafe 消除必要的请求/重试隔离。
- reasoning 清理先判断是否需要修改，仅拼接需要删除的成员范围；重复键、异常 UTF-8 和浮点解码溢出回到原解码路径。清理范围和数组继承规则保持原行为，其余数字与原始片段不重写。
- Responses 文本桥接在不需要提取额外工具或重写命名空间时保留已复制的 Input；始终验证 JSON 和顶层形状。数组含转义时保守使用原转换，异常 UTF-8 保留原解码规范化。没有新增原生透传规则。
- Claude 工具结果的名称只用请求内索引，保留原扫描的首次命中、空 ID、显式名称和前向引用；不引入全局工具缓存。
- 本地限流预算按实际流量增长，用一个桶级 LRU 索引清理空闲 key。加权、预留、取消和 RetryAfter 使用同一锁维护，过期/取消释放预留 ID；拒绝请求也更新活动时间，避免清理器提前清除仍在受限的热 key。模型请求预算的 Redis 路径不变。
- 共享本地限流器的清理周期不等于每个 key 的实际窗口；删除空闲桶前确认最后记录也已过期，长窗口桶不能阻止后续短窗口桶回收。
- HTTP/2 健康探测仅用于 HTTP 长流 profile（包括向上游发流但向客户端聚合的请求），默认读空闲 30 秒发 PING，15 秒未确认则断开。合法静默生成由 H2 PING ACK 保持，不以无 token 判断断连。`RELAY_H2_READ_IDLE_TIMEOUT=0` 禁用；`RELAY_H2_PING_TIMEOUT` 配置确认等待，非正数回退 15 秒。环境变量变更后重启进程。
- 长流 profile 纳入现有有界客户端缓存，渠道设置失效时清除两个 profile。HTTP/1 不启用探测；只在分片完成后的每个独立 Transport 上调用 x/net/http2.ConfigureTransports，不能 Clone 已配置的 Transport 并共享捕获旧连接池的 TLSNextProto 回调。Go1.25.1 的 net/http.Transport.HTTP2 字段尚未生效，不依赖它。
- 普通/SSRF 客户端缓存共用查找入口；初始化、读取、创建发布和 Reset 使用同一锁，不暴露中间 nil，也不允许锁外构造在 Reset 后晚发布。构造没有网络 IO；只关闭空闲连接，在途响应可继续完成。
- 并发槽属于具体请求，由既有 TokenRequestLimit defer 幂等释放，保存真实后端与 Redis 客户端。Redis 槽使用唯一 ZSET 成员和 Redis 时间，30 秒续租两分钟租约；丢失槽位或持续续租失败时取消对应请求，先停止 worker 再释放，仅删除自己，不复活旧成员。单次续租最多 15 秒；仅启用 Redis 并发上限的请求增加 worker，未另建调度器。新键使用 v2，发布需排空旧请求；故障时保留实例内回退，不承诺分区期间精确的跨实例并发上限。
- HTTP 响应 Close 先取消当前 attempt，再等待 Read 退出并关闭底层响应，Close 幂等。不取消父请求，保留 failover；不把此顺序用于 Responses WebSocket 合成响应。WS turn 必须先解除取消回调并判断可复用状态，否则正常结束也会错误销毁会话连接。

## 理由与边界

这些是对现有热路径和资源生命周期的局部适配，不增加数据库表、外部队列或第二套调度器，不改变计费与语义提交条件。HTTP/2 探活解决静默断连尾延迟，不保证正常连接吞吐提高；阶段微基准不能推算整站吞吐和 P95。
