# ADR-022：Claude 扩展字段的协议兼容与渠道故障切换

状态：已接受；2026-10-28。本地修复，未发布部署。

## 背景

Claude Messages 请求可能包含 Responses 无法表示的合法扩展字段。把这类转换失败
当作 malformed 或 `SkipRetry` 会阻止同一请求尝试兼容渠道；无条件删除字段又会改变
客户端语义。

## 决策

- 转换器用类型化错误区分“有效字段无目标表示”和结构错误。前者是当前路由的局部
  协议不兼容，后者继续作为请求错误处理。
- 只有全局模型端点归一化到 Responses、渠道原生类型为 Anthropic、且没有显式模型
  绑定或 Codex 身份要求时，才恢复原生 Messages 适配器。显式路由优先级不被回退
  覆盖。
- 协议不兼容允许故障切换，但不污染渠道健康、自动禁用或路由冷却；最终无兼容路径
  时返回固定公共 400，原始转换原因只写管理员诊断。
- 回退不重新初始化渠道元数据，不重复执行已完成的输入参数覆盖，避免模型映射、
  认证和非幂等操作跨尝试变化。

## 边界与验证

原生回退保留 Claude 扩展字段；若请求无法由任何候选协议表达，仍明确拒绝。集成测试
覆盖流式/非流式、显式绑定、固定路由、malformed 请求、Codex 保护和单次覆盖语义。
