# ADR-011: 持久化首语义输出期限

后台选项 RelayFirstByteTimeout 接受 1–86400 整数秒。保存值覆盖环境变量
RELAY_FIRST_BYTE_TIMEOUT；未保存时沿用部署默认值（通常 15 秒）。每次请求
在首次进入流式尝试时记录快照，重试及扫描器使用同一值，避免在线修改导致
同一请求的两个计时器使用不同期限。

首输出期限包括响应头等待和无语义 SSE 前奏；首次有效输出之前不启动流空闲
计时器，之后 STREAMING_TIMEOUT 控制无数据间隔。客户端取消及独立整体请求
超时仍有优先终止权。非流式与 Realtime 不新增首语义期限。

管理员错误展示读取 admin_info.real_error。公共 content 和普通用户日志的
脱敏边界保持不变。配置无需修改数据库结构。
