# RenewAPI Tasks

Use `tasks/active/` for work that spans modules, sessions, migrations,
providers, routing, security, upstream audits, or releases. Keep active files
focused on the current state and handoff. Move a task to `tasks/archive/` only
after validation succeeds.

- [Template](TEMPLATE.md)
- Active work: inspect `active/`
- Completed work: inspect `archive/` when historical context is needed
