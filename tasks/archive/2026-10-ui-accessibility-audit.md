# 2026-10 UI 可访问性与旧前端清理

状态：修复、classic 退役、v1.2.0 发布、生产热切换与本次清理完成。基线 `b1b1756` / v1.1.3。

## 授权与边界

用户要求核实并修复 F1–F14 审计项，并追加允许移除旧前端、无用旧资源与依赖。保留业务权限、计费、生产配置和用户数据；不删除 Git 历史或仍被生产 Caddy 使用的旧分块缓存。

2026-10-05 用户追加授权：检查提交，通过 GitHub Actions 构建到 Releases，由服务器代理下载并热切换；验收成功后删除本次中间文件和临时备份。此次不清理既有历史 Releases、标签、镜像或此前备份。

## 实现

- F1：文档语言跟随 i18next 的初始解析与语言切换；挑战页用局部 lang，不再恢复过期的全局 lang。当前菜单三种语言，资源七种。
- F2/F3：默认中性画布保留；明确选择的预设控制主色/表面。状态填充色固定语义色相，危险操作恢复红色，文字使用专用墨色，去掉按原生色板类名强制黑白的覆盖。常用状态增加图标冗余。
- F4：新账号默认 default 密度、sans 字体，启动器与 provider 共用默认值；已有选择和升级前偏好保留。小于 12px 的 Tailwind 固定文字改为 text-xs，紧凑字号有下限，核心按钮目标不小于 24px，触屏控件优先 44px。
- F5：迁移裸 text-success/warning/info/destructive 到文字 token，新增 ESLint 规则和全源码语义色检查（含基础组件）。
- F6/F7：输入框边界增强，基础组件用 outline-hidden，并为 forced-colors 添加系统焦点轮廓。
- F8：统一图表分类色，增加线型与符号冗余；避免宣称仅靠 12 种颜色就能覆盖所有色觉差异。
- F10/F12/F13：减少覆盖规则，明确字体旧键的兼容含义，通知/提示框跟随实际表面，浏览器 theme-color 从全局实际页面同步。
- classic：移除 439 个受版本控制的旧前端文件和构建/嵌入分支。旧设置回落 default，保留已知旧 URL 跳转。移除闲置 Recharts/resizable/auto-skeleton 组件及 10 个确认无引用的直接依赖；保留仍有引用的图标、动效、引用轮播与流程图依赖。
- 更新 design-qa.md，将 Aurora 结果明确归档为历史证据。
